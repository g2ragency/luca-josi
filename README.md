# luca-josi

Sito di Luca Josi, realizzato con Next.js (React), TypeScript e Tailwind CSS. Pubblicato su Vercel.

## Sviluppo locale

```bash
npm install
npm run dev
```

Il sito è disponibile su http://localhost:3000.

## Comandi

- `npm run dev`: server di sviluppo
- `npm run build`: build di produzione
- `npm run lint`: controllo del codice
